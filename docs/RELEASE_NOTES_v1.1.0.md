Midas v1.1.0 - the first installable release.

## Install

Download **Midas-Setup.msi** below and run it - that's it. It installs
Midas for every user of the PC with Start-menu and desktop shortcuts, and
uninstalls cleanly from *Settings > Apps & features*.

> **SmartScreen note:** the installer is not code-signed yet, so Windows may
> show "unknown publisher" on first run. Click *More info > Run anyway*.

## What's new

- **Studio Crop tab** - visually crop any finished video: scrub to a frame,
  drag golden guides over a live preview, export as a copy or in place.
- **Clip downloads for Instagram, TikTok and Reddit** - download just a
  time-section, same as YouTube.
- **Cover art in the Downloads list** for local/converted files.
- **Much faster link analysis** on every platform, and the link bar now
  re-analyzes automatically when you edit or clear it.
- **Calmer download card** - hover animations removed, entrance and click
  feedback kept.
- **SoundCloud fixes** - readable playlist names, no bogus video-quality
  selector, clear rate-limit messages, and set previews that never hang.
- **Settings that survive** - your settings, history and logs now live in
  `%APPDATA%\Midas` and are migrated automatically from older versions.
- Full details in [CHANGELOG.md](../CHANGELOG.md).
